# Кручение коробчатой балки A2

Образец A2 испытан без предварительного напряжения. На концах
установка позволяла продольное перемещение и депланацию, угол
задавался по деформации. Среднее закручивание определялось по двум
сечениям AA и JJ на базе 5,35 м. Авторы относят A2 к образцам
с пластичным разрушением. [Статья, разделы 4–5](Lopes-Bernardo-2009-PureTorsion.pdf).

| Величина | Из источника |
| --- | --- |
| Сечение | 600×600 мм, стенки 100 мм. На внутреннем контуре четыре фаски (рис. 4) |
| Продольная сталь | 4Ø12 в углах, по три Ø10 на каждой стороне (рис. 4, табл. 1) |
| Хомут | Ø8 с шагом 80 мм, расстояние между осями ветвей 538×531 мм (табл. 1) |
| Бетон | Измеренная средняя цилиндровая прочность 47,3 МПа (табл. 1) |
| Сталь | Средняя текучесть 686 МПа при деформации 0,00343 (раздел 4.2) |
| Первая трещина | 109,5 кН·м при 0,064°/м (табл. 3) |
| Текучесть хомута | 239,4 кН·м при 1,08°/м (табл. 3) |
| Текучесть продольной арматуры | 247,1 кН·м при 1,17°/м (табл. 3) |
| Опытный максимум | 254,8 кН·м при 1,66°/м (табл. 3) |
| Начальная жёсткость | 97 950 кН·м² (табл. 3) |

В отчёте о разрушении A2 отнесён к пластичной группе. Авторы описывают
развитие винтовой поверхности трещин после текучести арматуры в этой
группе. Для A2 средний шаг наклонных трещин составил 153 мм, средний
угол к оси балки — 47,6°. Эти данные характеризуют распределение трещин
по длине балки. Для проверки секционной модели связь между местным
закручиванием и измерением на базе 5,35 м требует отдельного расчёта.
[Lopes и Bernardo, §6.1 и табл. 4](Lopes-Bernardo-2014-TorsionFailure.pdf).

Фаски приняты по 50 мм по масштабу рисунка. По уточнённым данным
стенка A2 имеет толщину 107 мм, предел текучести продольной стали
672 МПа, а стали хомутов 696 МПа. В табл. 4.1–4.2 Martins
модуль бетона 36,1 ГПа, прочность при растяжении 3,5 МПа и
деформация на пике сжатия 0,002 приведены как параметры расчёта.
Исходный отчёт об испытании указывает среднюю прочность при сжатии,
а измерения модуля, прочности при растяжении и энергий разрушения отсутствуют.
[Bernardo и соавт., табл. 6](https://doi.org/10.3846/13923730.2013.801895) ·
[Martins, табл. 4.1–4.2](https://ubibliorum.ubi.pt/bitstreams/c660cc5d-d900-4fed-a379-bb7ff13113e4/download).

В нелинейном расчёте координаты осей продольных стержней уточнены
по рисунку и известным осям ветвей хомута. Для обоих вариантов
`ν = 0,20`, модуль стали 200 ГПа, диаграммы стали имеют плато,
характерная длина бетона 125 мм. В номинальном варианте приняты
модуль бетона 35 ГПа, растяжение `fₜ = 0,302 f꜀^(2/3)` и
деформация на пике сжатия 0,0024. В обоих вариантах энергии приняты
как `Gₜ = 0,073 f꜀^0,18` и `G꜀ = (f꜀/fₜ)² Gₜ`, где `f꜀` и `fₜ`
даны в МПа, энергии в Н/мм. Первый расчётный признак повреждения
зафиксирован при превышении отношения израсходованной к полной
энергии растяжения 10⁻⁶ хотя бы в одной точке бетона. Это диагностическая
величина. Опытное трещинообразование зарегистрировано визуально.
[Материальная модель Poliotti и Bairán](https://doi.org/10.1016/j.engstruct.2019.03.086).

Без арматуры получены константы Сен-Венана на трёх независимых сетках.

| Стенка, мм | Площадь, мм² | `J`, 10⁹ мм⁴ (сетки 800, 200, 50 мм²) |
| --- | --- | --- |
| 100 | 205 000 | 14,4295 / 14,4259 / 14,4246 |
| 107 | 216 004 | 14,9288 / 14,9249 / 14,9238 |

Воспроизведение — `python tools/validate_lopes_a2.py --wall-mm 100`
или `--wall-mm 107` с библиотекой `sectionproperties`.
[Методика расчёта](https://sectionproperties.readthedocs.io/en/stable/user_guide/analysis.html).

При `ν = 0,20` обратная оценка модуля по опытной начальной жёсткости
и самому мелкому КЭ-разбиению составляет 16,3 ГПа для стенки 100 мм
и 15,8 ГПа для 107 мм. Эти оценки только характеризуют расхождение
между расчётной и измеренной упругими жёсткостями.

## Кручение при постоянном сжатии

Внешние расчёты Bernardo и Taborda включают `N = −1279,1 кН`
и сравнимый случай чистого кручения. При сжатии их трёхмерная
модель Abaqus дала предельный момент 267,07 кН·м, пространственная
ферменная модель — 336,13 кН·м. При `N = 0` это 244,75 и
257,73 кН·м соответственно. КЭ-модель использует балку длиной
1,5 м, две упругие зоны по 0,25 м у торцов, бетонные элементы C3D8R
и арматуру внутри бетонных элементов. Для `N + T` приведены
теоретические кривые. Эксперимент A2 относится к `N = 0`.
[Bernardo и Taborda, табл. 3–4 и рис. 8, 10, 12](https://www.mdpi.com/2673-3161/1/1/6).

Данные кривых снимаются скриптом `tools/compare_lopes_a2_curves.py`
из векторных рисунков указанной копии PDF. NDM интерполируется
только между принятыми шагами. [Журнал результатов](../../docs/reports/Coupled6DProgress.md#42-кручение-a2-и-влияние-продольного-сжатия).

## Возврат возле растягивающей оси

Два отклонённых состояния бетонной точки 7 воспроизводятся командой
`python tools/validate_a2_tensile_return.py`. Для записанных эффективных
проб и принятой истории исходная дилатансия не даёт корня возврата.
Численный эксперимент со сглаживанием продолжил расчёт чистого
кручения. При 1,66°/м получено 272,18 кН·м на одном интервале
базиса и 263,32 кН·м на двух, при 254,8 кН·м в опыте. Напряжения арматуры
при опытных углах её текучести остались ниже предела.
[Вывод формул и проверка чувствительности](../../docs/reports/Coupled6DProgress.md#50-отсутствие-локального-корня-возле-растягивающей-вершины-a2).

## Независимая оценка кручения по текучести стали

Для чистого кручения принято, что поток проходит по осям хомута
538×531 мм. Площадь контура `A₀ = 285 678 мм²`, периметр
`p₀ = 2138 мм`, площадь одной ветви `Aₜ = 50,2655 мм²`,
суммарная площадь продольных стержней `Aₗ = 1394,8671 мм²`.
При одновременной текучести в упрощённой ферме
`q = Rₜ·cot θ = Rₗ·tan θ`, где `θ` — угол бетонных раскосов
к продольной оси, `Rₜ = Aₜ·fᵧₜ/s`, `Rₗ = Aₗ·fᵧₗ/p₀`,
`fᵧₜ` и `fᵧₗ` — пределы текучести соответствующей стали,
`s = 80 мм` — шаг хомута. Тогда `T = 2A₀·√(Rₜ·Rₗ)`.
Отдельно оговорены пренебрежение растяжением бетона, равномерное
распределение продольной стали и отсутствие проверки сжатых раскосов.
[Общее равновесие потока и ферменной модели, формулы (6)–(8)](https://www.mdpi.com/2673-3161/1/1/6).

| Сталь хомута, МПа | Продольная сталь, МПа | Угол раскосов | Оценка T, кН·м | Относительно опыта 254,8 кН·м |
| ---: | ---: | ---: | ---: | ---: |
| 686 | 686 | 44,46° | 250,95 | −1,51% |
| 696 | 672 | 44,96° | 250,18 | −1,81% |

Оценка проверяет порядок момента при развитой работе стали.
Нелинейный расчёт в окрестности опытного максимума должен также
проверяться по последовательности текучести и напряжениям арматуры.
