# Изгиб с кручением образца TBU3

Образец TBU3 из серии Onsongo нагружали в центральном участке с постоянными
изгибающим и крутящим моментами. На участке нет поперечной и продольной
сил. Экспериментальные точки сравнения относятся к центральному участку.
Диссертант Yamamoto вычислял закручивание как средний поворот на единицу
длины участка 1,75 м. Данные о геометрии и схеме армирования приведены у
Bairán в табл. 6.7 и на рис. 6.39. [Диссертация Bairán, с. 184–186](Bairan-2005-TINSA-thesis.pdf).

| Параметр | Принято для расчёта |
| --- | --- |
| Коробка | 508×410 мм, все стенки 76 мм, внутренний проём 356×258 мм |
| Продольная сталь | 7 стержней № 8 по нижней полке, 3 № 4 по верхней, по 3 № 3 в каждой стенке |
| Площади стержней по Yamamoto | 510, 129 и 71 мм², соответственно |
| Хомут | Замкнутый, площадь 129 мм² по Yamamoto, шаг 150 мм по схеме Bairán |
| Бетон для постановки Yamamoto | `fc = 34,8 МПа`, `ft = 1,95 МПа`, деформация при пике сжатия 0,0045 |
| Продольная сталь № 8 / № 4 / № 3 | Текучесть 436 / 393 / 552 МПа, модуль 194200 / 201900 / 205100 МПа, модуль упрочнения 9000 / 4900 / 9000 МПа |
| Сталь хомута | Текучесть 379 МПа, модуль 198500 МПа, модуль упрочнения 5200 МПа |
| Траектория | Постоянный изгибающий момент 29,6 кН·м. На каждый шаг добавляется 14,87 кН·м изгиба и 10,35 кН·м кручения |
| Опытный предел по табл. 4.2.4 | 327 кН·м по изгибу, 207 кН·м по кручению |

Материалы, траектория и опытные предельные усилия приведены в таблицах
4.2.1–4.2.4. В опыте отмечено течение нижней продольной и поперечной
арматуры и последующее дробление бетона. В том же источнике есть расчёт
оболочечными элементами. Прочие образцы серии имеют локальные отклонения
геометрии. У TBU2 толщина верхней полки местами 44 мм при проектных 80 мм.
[Диссертация Yamamoto, с. 62–68 и 79–83](https://www.collectionscanada.gc.ca/obj/s4/f2/dsk1/tape8/PQDD_0002/MQ45940.pdf).

В макросе оси стержней и отступ оси хомута оценены по рисунку. Отступ оси
хомута принят 32 мм. Исходные упругие параметры бетона `Ec = 30000 МПа`,
`ν = 0,20`, параметры регуляризации `Gt = 0,12 Н/мм`, `Gc = 80 Н/мм`
и характеристическая длина 125 мм приняты для диагностики. Модуль
упрочнения действует сразу после текучести, а в табл. 4.2.2 опубликовано
плато перед упрочнением. Установленная предельная деформация 0,05
диагностическая. Упомянутое у Yamamoto эквивалентное расстояние 70 мм
между поперечными стержнями в текущей постановке не использовано.
В собственной модели Kagermanov и Ceresa деформация при пике сжатия
принята 0,0031. Эти различия фиксируются до сравнения и не калибруются по
опытному пределу. [Kagermanov и Ceresa, § 5.2, рис. 14–15](https://onlinelibrary.wiley.com/doi/10.1155/2018/8596970).

Экспериментальная и авторская расчётная кривые `T(θ)` извлечены из
векторного рисунка 14b. Оси откалиброваны по отметкам 0, 0,03 рад/м
и 250 кН·м. Результат сопоставления округляется до целых кН·м, исходная
точность лабораторных отсчётов неизвестна. Для воспроизведения используется
`python tools/validate_tbu3_torque.py literature/Coupled6D/Kagermanov-Ceresa-2018.pdf --native-report <отчёт>`.
[Статья, с. 10](Kagermanov-Ceresa-2018.pdf) ·
[Журнал сравнения](../../docs/reports/Coupled6DProgress.md#40-продолжение-ветви-tbu3-и-проверка-времени-решения).

## Сопоставление по кривизне

Рисунок 14a той же статьи содержит экспериментальную кривую и
нелинейный расчёт Kagermanov и Ceresa. Из PDF извлечены осевые
линии кривых. Координаты откалиброваны по отметкам 0 и 0,01 м⁻¹
на горизонтальной оси и 50 и 250 кН·м на вертикальной. Ширина
прорисовки линий 0,5 пункта PDF и чувствительность к выбору
делений дают оценку погрешности чтения порядка ±4 кН·м.
Это оценка разрешения графика. Разброс лабораторных измерений
и допуск физической валидации из неё не следуют.

Значения NDM интерполированы по 153 принятым равновесиям из
`docs/regression/Coupled6D/TBU3TwistExtended/Native.txt`.
Ряд этой проверки продолжался по углу закручивания. В таблице
строки относятся к общей кривизне. Продолжения за пределами
исходных кривых нет.

| Кривизна, м⁻¹ | Опыт, кН·м | Kagermanov и Ceresa, кН·м | NDM, кН·м |
| ---: | ---: | ---: | ---: |
| 0,001 | 54 | 47 | 58 |
| 0,003 | 115 | 111 | 118 |
| 0,004 | 149 | 154 | 135 |
| 0,006 | 215 | 242 | 178 |
| 0,0075 | 257 | 300 | 211 |
| 0,009 | 291 | — | 243 |

При 0,006 м⁻¹ расчётный изгибающий момент NDM меньше опытного
примерно на 37 кН·м. Эта разница больше погрешности чтения.
На поздней части пройденной ветви отставание проявляется и по
закручиванию. Сопоставление двух кривых усиливает наблюдение
о расхождении в совместной деформации. Из сравнения нельзя
изолировать влияние закона бетона, арматуры или дискретизации.

Команда воспроизведения:

```powershell
python tools/validate_tbu3_torque.py literature/Coupled6D/Kagermanov-Ceresa-2018.pdf --native-report docs/regression/Coupled6D/TBU3TwistExtended/Native.txt --curvature
```

При сопоставлении по одной номинальной паре усилий скрипт находит
первое возрастание через заданный момент на каждом из двух графиков.
Изгиб и кручение сопоставляются по одному номинальному этапу
нагружения, деформации считываются с графиков по отдельности. Все 153
записи NDM предварительно проверены на соответствие заданной
пропорции с абсолютным расхождением до 0,000018 кН·м.

| ---: | ---: | ---: | ---: | ---: |
| 4 | 89,08 | 41,40 | 2,11 / 2,42 / 1,99 | 2,19 / 2,60 / 2,65 |
| 8 | 148,56 | 82,80 | 3,99 / 3,88 / 4,62 | 7,36 / 6,91 / 9,30 |
| 12 | 208,04 | 124,20 | 5,77 / 5,21 / 7,36 | 13,31 / 12,55 / 17,54 |

На этапе 12 кривизна NDM выше опытной примерно на 28%, закручивание
выше на 32%. До этапа 16 сохранённая ветвь NDM не дошла.
Таблица воспроизводится той же командой с `--load-path` вместо
`--curvature`.

На рисунке 15b показана деформация хомута на середине высоты
стенки. Записанное NDM наибольшее использование по контуру
относится к контрольной точке всего хомута. Для количественного
сопоставления с рисунком нужна деформация в измерительной точке.
[Kagermanov и Ceresa, рисунки 14–15](Kagermanov-Ceresa-2018.pdf).

## Второй внешний расчёт и расхождение опубликованных опытных рядов

В статье Yamamoto и Vecchio рассчитан участок 648 мм с 56
четырёхслойными оболочечными элементами и жёсткими участками
у торцов. На их общей схеме серии TBU/TBO верхняя стенка 80 мм,
нижняя 76 мм, шаг поперечной стали обозначен 70 мм. В NDM
приняты стенки по 76 мм и шаг 150 мм по схеме Bairán. Эти
различия вместе с законом бетона и установкой опыта ограничивают
количественное сопоставление с RASP. [Yamamoto и Vecchio, с. 196–197](Yamamoto-Vecchio-2001-RASP.pdf).

На рис. 9a оцифрованы 11 сечений опытной линии и доступная
пунктирная линия RASP. Шкалы восстановлены по делениям 0 и
0,04 рад/м, 0 и 200 кН·м, положения линий усреднены по центрам
тёмных пикселей. Погрешность считывания порядка ±4 кН·м.
В таблице закручивание в 10⁻³ рад/м при одной номинальной паре
усилий.

| Изгиб, кН·м | Кручение, кН·м | Опыт ACI | RASP | Опыт на рис. 14b | Kagermanov и Ceresa | NDM |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 148,56 | 82,80 | 9,29 | 11,72 | 7,36 | 6,91 | 9,30 |
| 208,04 | 124,20 | 16,56 | 20,76 | 13,31 | 12,55 | 17,54 |
| 252,65 | 155,25 | 23,10 | 29,16 | 17,99 | 17,33 | 27,70 |

При закручивании около 0,024 рад/м опыт ACI даёт 158 кН·м,
опыт на рис. 14b — 187 кН·м. Разница около 28 кН·м превышает
разрешение обоих графиков. Первичные измерения и сопоставимость
базы усреднения закручивания нужно подтвердить, прежде чем
принимать одно из значений для калибровки. Для кривизны
сопоставление ограничено рис. 14a.

```powershell
python tools/validate_tbu3_torque.py literature/Coupled6D/Kagermanov-Ceresa-2018.pdf --native-report docs/regression/Coupled6D/TBU3TwistExtended/Native.txt --rasp-pdf literature/Coupled6D/Yamamoto-Vecchio-2001-RASP.pdf
```

В диссертации Yamamoto дополнительно приведены кривизна и
деформации хомута, отмечены паузы при нагружении и влияние
ползучести. В табл. 4.2.4 для RASP и опыта приведены
`M = 327` кН·м и `T = 207` кН·м. Принятая ветвь NDM до
этих значений пока не доведена. Локально доступна авторская
статья. Загрузка полной диссертации из архива по-прежнему
недоступна из-за HTTP 403 и тайм-аута разных адресов.
[Архив Канады, § 4.2](https://central.bac-lac.gc.ca/.item?app=Library&id=MQ45940&oclc_number=1006745201&op=pdf).

Исходная диссертация Onsongo найдена по библиографической записи.
[Карточка диссертации Onsongo](https://erepository.uonbi.ac.ke/items/02503667-92a1-4ca1-8778-4d7e70355fa1).
