# Численная организация локального возврата

Сохранены исходные страницы официальной документации MOOSE по
фиксированной ревизии из `Sources.json`. Они описывают скалярное
замыкание локальной пластической поправки, отделение материального
решения от общего расчёта и варианты дробления шага. Это ориентир
для организации численного метода; описанная там поверхность J2
не заменяет поверхность Барселоны и потенциал бетона проекта.

В VBA используется собственное замыкание исходной дилатансии.
Прогноз из дроблений задаёт начальное приближение, затем снова
проверяется полный исходный шаг. Формулы J2, нормативные параметры
и сторонний программный код из документации не переносились.
Локальный успех не подтверждает равновесие сечения или его предел.

Прямая загрузка сайта документации отклонена Cloudflare; сохранены
те же исходные страницы из официального открытого репозитория,
с URL, датой, размером и SHA-256. Код страницы проверки доступа
не исполнялся и не сохранялся как литературный источник.
