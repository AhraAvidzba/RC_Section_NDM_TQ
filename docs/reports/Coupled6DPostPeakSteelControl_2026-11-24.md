# Постпиковое управление деформацией стали: проверка и остановка на 3%

Этапы 671–673 продолжают проверенную историю 670 с 146 состояниями.
Определяющий физический предел всего сечения не подтверждён. Рабочие
численные исходники, выпускаемая книга и main на этих этапах не менялись.

## Происхождение и ограничения

Первоначальные 103 поля и нагрузки перенесены из исходного двоичного
снимка точно. Следующие 43 поля и нагрузки восстановлены из CSV с
15 значащими цифрами. Исходные машинные биты этого хвоста отсутствуют.
Все пространственные уравнения и шесть усилий восстановленной истории
проверены независимо; интегрирование материала остаётся нативным VBA.
Это не новый полный холодный запуск от нулевого состояния.

Исходная конечная точка: lambda=1.09533730272841 после локального пика
lambda=1.12102609132239. Автоматический выбор растущей меры определил
поперечный стержень, точку 37, с деформацией 4.627532757243622e-5
и собственным пределом 0.02. Номер точки не передавался селектору.
Пределы стали, закон бетона, первичные 30 итераций и силовые допуски
сохранены. Численные коэффициенты шага не являются физическими порогами.

## Этап 671: четыре независимые пробы

Каждая проба начинает с одной и той же истории 146 полей. Прогноз
по секущей использует только два последних принятых состояния.
Возвращённая решателем мера управления записывается отдельно, чтобы
не выдавать заменённую цель за выполненную исходную.

Для обоих найденных корней независимо проверены 147 полей, все
пространственные уравнения, связи, шесть усилий, исходное управление
и направление приращения. У прямого кандидата растёт H огибающих;
H не отождествляется с полной термодинамической диссипацией.
Оба корня используют исходную меру, без подмены восстановленной мерой.
Ни один новый шаг не принят рабочим контроллером.

Нативный запуск 1628 завершён exit0; это успешная запись численных
исходов, а не PASS прочности. Собственный Excel
26276/639310844542267572 закрыт. При последующей проверке PID26276
принадлежит SearchFilterHost.exe с другим временем запуска; этот
посторонний процесс не затрагивался.

Книга 671 имеет SHA-256
`75DCDE220C76E477D9EDC1989285AD8F304EC810E4729FBBC1A5AD0CE23EC325`.
После импорта только тестового модуля сверены все 255 компонентов;

идентификаторов VBE. Компиляция и сохранение завершены, собственный

## Этап 672: проверка первым половинным шагом

Использована та же фактическая скомпилированная книга, без импорта кода.
Вместо успешной цели пробы 0 проверена её половина:
epsilon=4.876954315648966e-5, доля шага 0.125. Начало и прогноз исходные.

Решение не найдено за 53.41015625 с. Запуск 31004 завершён exit0,
результат пробы — NoVerifiedEquilibrium. Все 146 исходных равновесий
независимо проверены. Собственный Excel5868/639310849699499844 закрыт.
Второй половинный шаг не запускался: необходимое первое состояние
не получено. Успешная проба 671 поэтому остаётся кандидатом; проверки
сходимости по шагу и надёжного продолжения нет. В рабочий код она
не перенесена. Уменьшение шага не гарантирует попадания в нужный корень.

## Этап 673: подготовленная диагностика существования

Подготовлены две пробы той же промежуточной цели: постоянное принятое
поле и интерполяция между принятым полем и уже найденным корнем 671.
Последнее использует известное будущее поле исключительно для диагностики
существования; это не доступный штатному расчёту прогноз. Будущий корень
не добавляется в принимаемую историю, материалы и допуски не меняются.

В частную книгу импортирован только тестовый модуль. Компиляция 55564
и сверка 38875 завершены exit0. Все 255 компонентов проверены;
254 прочих соответствуют родителю с учётом регистра VBE. Собственный
Excel30100/639310852987054159 закрыт. Книга имеет SHA-256
`406B16817CB1D7C1E7399984F572CAC31AD294CF9F71A118EF7212489535BDE2`.
Одиннадцать непосредственно используемых файлов подготовки/проверки
закреплены в MidSeedValidation/ValidatorPins.json.

Численный запуск 673 не выполнялся: фактический остаток квоты достиг
3%, после чего по указанию пользователя новые расчёты не запускаются.
Все уже запущенные задания завершены. Следующее действие после
возобновления — проверить пины и ресурсы, затем один направленный запуск
Run-TestPersistentHController.ps1 для этой книги и независимая проверка
Check-TestSteelMidSeedDiagnostic.py. Его исход не предрешён.
