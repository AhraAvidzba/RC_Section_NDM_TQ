# Переключатель пространственного бетона: рабочие CDP и ASD

В исходники добавлен выбор `Coupled.ConcreteLaw = CDP / ASD`. Полностью отдельная книга собрана из текущего дерева исходников и скомпилирована Excel. Успешно выполнены восемь небольших расчётов рабочего ядра, материальный повтор ASD в OpenSees и две нелинейные регрессии CDP. Визуальная приёмка выпадающего списка остаётся незавершённой; согласованная выходная книга не заменена, слияния в `main` нет.

## Реализация

`CCoupledConcreteCalibration` готовит общие одноосные огибающие из заданных E, прочностей, деформации пика, энергий и характерной длины. Пространственный CDP использует выделенные из его инициализации формулы без изменения их содержания. Для ASD по этим огибающим один раз строятся неизменяемые таблицы; кэш действует внутри запуска и разделяет точные наборы характеристик.

Рабочий выбор ASD использует однократное обновление `ASDConcrete3D` без IMPL-EX, с идентификатором `ASD-NativeStep-Cdf0`. Существующая замкнутая интеграция `ASD-Closed-Cdf0` сохранена для явного программного подключения. Идентификатор фактически применённого закона сохраняется вместе с диаграммами. ASD включает упрощённую пластичность; `cdf=0` означает нулевое перекрёстное повреждение, а не отсутствие пластичности.

Настройка находится в компактной таблице связанного расчёта Config; диапазон таблицы расширен на одну строку в каталоге сборки и `WorkbookLayout.json`. Чтение выполняется через `CSystemSettingsReader`. Неизвестный закон отклоняется с причиной и ссылкой на настройку. По умолчанию сохранён CDP. Порядок дальнейшей разработки и сравнений — сначала ASD, затем CDP, согласно указанию пользователя.

## Фактически выполненные проверки

Свежая сборка 1017 содержит 255 компонентов VBA. Проверены 249 рабочих и тестовых исходников; шесть изменённых компонентов сопоставлены с закреплёнными исходниками с сохранением исполняемых строк, точных значений и типов числовых литералов. При сравнении учитываются регистр и пробелы исполняемых токенов VBE, запись чисел и кодовая страница комментариев: например, недоступная в CP1251 греческая буква в комментарии может сохраняться как «?». Содержимое строковых литералов этой нормализацией не меняется. Для части неизменённых компонентов отличие представления чисел допустимо только при совпадении с ранее опубликованным нативным компонентом; такие случаи отдельно перечислены в доказательствах. Модули документов этим аудитом исходников не охвачены.

В книгу 1018 добавлен только тестовый модуль; остальные 255 компонентов сохранены с учётом регистра идентификаторов VBE. В каждом из двух законов с нулевой истории решены: чистый изгиб, чистое кручение, небольшое сочетание всех шести усилий и изгиб с другим набором прочностей. Все восемь нагрузок находятся в упругой области. Проверены результирующие и совпадение 56 физических координат; четыре множителя кинематических связей учитываются отдельно. Успех этих случаев не подтверждает нелинейную несущую способность.

Фактические таблицы ASD и девять последовательных тензоров дополнительно переданы настоящему OpenSees 3.8.0. Для 54 компонент напряжений наибольшая ошибка составляет **5,8319·10⁻¹⁰ МПа** при допуске 10⁻⁷ МПа. Это материальный повтор, без решения равновесия сечения внешней библиотекой. Нелинейные регрессии `RunTestCoupledEnvelope` и `RunTestCoupledConcreteResponse` дали **39 пройденных проверок, 0 ошибок**, с подтверждённой сохранностью книги и закрытием собственного Excel.

На малых упругих нагрузках время внутри тестируемого вызова составило 0,19–0,29 с для CDP и 0,40–0,67 с для ASD. Эти замеры не включают полный пользовательский запуск с отчётом и схемой и не являются проверкой целевых 10 с на сочетание. Они также не подтверждают общего преимущества ASD по скорости: его посттрещинное поведение проверяется отдельно.

## Выпадающий список и ограничение приёмки

В собственной нативной копии Excel оба значения по отдельности выбирались программно, сохранялись, повторно открывались, принимались проверкой данных и правильно читались рабочим VBA. Склеенные `CDP,ASD`, `CDP;ASD` и посторонний `UnknownLaw` отклонены. Зафиксирована фактическая `Formula1 = CDP;ASD` внешнего COM API этой локали; разделители в тесте не нормализовались. Проверены центрирование, отсутствие переноса и заливка RGB(255,242,230); исходное значение CDP восстановлено.

Показ пунктов раскрытого списка и выбор каждого пункта через видимый интерфейс **не подтверждены**. Захват экрана завершился ошибкой GPU `0x887A0005`, геометрия ввода была недоступна; пользователь сообщил о выключенном мониторе. У собственного UI-процесса затем возник COM busy `0x800AC472`; его точная личность, исходная книга и закрытие сохранены в доказательствах. API-проверка не заменяет обязательную визуальную приёмку по AGENTS.md. Повтор визуальной проверки отложен до доступности интерфейса.

## Доказательства и дальнейшая работа

[Summary.json](evidence/Coupled6DSelectableMaterials_2026-11-26/Summary.json), [Files.json](evidence/Coupled6DSelectableMaterials_2026-11-26/Files.json) и [RawEvidence.tar.xz](evidence/Coupled6DSelectableMaterials_2026-11-26/RawEvidence.tar.xz) сохраняют точные собранные книги, исходники, данные сборки, тестовые входы, журналы, исправления обвязки и проверяющие программы. Все 1415 логических файлов прочитаны из архива обратно и сверены по SHA-256. Заполненные ячейки свежей книги, книги с тестовым модулем и UI/API-копий сопоставлены по значениям, развёрнутым формулам, типам и адресам; изменение XML-сериализации общих строк, общих формул и кэша вычислений не считается изменением пользовательского ввода. Защищённая выходная книга в тестовом комплекте побайтно сверена с уже опубликованной версией Git.

Автоматический поиск предела, прохождение сложных сочетаний, тесты физических ограничений и полная приёмка ещё не завершены. Частные эксперименты с адаптацией продолжения не включены в рабочие исходники этого этапа. Полная серия 15 опытов Wang–Huang остаётся в [плане сравнения](../Coupled6DExperimentalComparisonPlan.md) после стабилизации обеих моделей.
