# Mx: влияние масштаба нагрузки и автоматический уточняющий повтор, 27.11.2026

В частной сборке ASD впервые подтверждён физический предел отрицательного Mx для реалистичного сечения: **109,798…109,802 кН·м**. Повтор автоматически уменьшает начальный множитель и точность поиска lambda в десять раз, если первая попытка не дала подтверждённого предела. Он воспроизводит целиком историю успешного ручного контрольного запуска. Это проверенный частный результат, а не универсальная настройка: положительный Mx и чистое T пока остаются NumFail. Рабочие исходники, публичная книга и её полный дамп не изменялись; кандидат1202 не принят в выдачу.

## Кандидат автоматического повтора1202

В фактически сохранённой269-компонентной книге изменён только CCoupledSectionAnalysis.268 остальных компонентов совпадают с1186. Первая попытка не изменена; второй существующий независимый ASD-повтор использует initialLambda/10 и lambdaTolerance/10 и существующее ограничение внешнего масштаба E·10⁻⁵. Если положительный Double для уменьшенного параметра не представим, повтор пропускается с явной диагностикой. Сохраняются исходный maximumLambda, материалы, силовые критерии, путь, лимит одного равновесия и максимум две попытки. Для двух NumFail сохраняется более высокая подтверждённая нижняя оценка. Физический отказ не подменяется успехом численного повтора.

Коэффициент10 — эмпирический вариант ограниченного резерва, а не доказанный оптимум. Пользователь отдельно потребовал автоматического подбора в будущей работе, без ручного изменения исходного момента. Для выполнения этого требования необходимо выбирать первый физический шаг по отклику подготовленного сечения и согласовать разрешение lambda с масштабом фактических усилий; затем проверить оба знака, другие геометрии и фиксированные компоненты LoadPath.

## Проверенные отрицательные варианты

- 1197: устойчивое Jacobi-разложение главных значений вместо тригонометрической ветви не решило точную замороженную цель; в код не принято.
- 1198–1200: нативные независимые продолжения по стали, с исключёнными линейными связями и по общему тензорному направлению добавили27 допустимых полей. Все повторены из исходной истории в свежем материальном контексте. Максимум нагрузки не увеличился, физическое верхнее плечо не найдено. Это не холодные успехи VBA.
- Профиль точной поправки: на доле1/128 невязка растёт, на1/1024 впервые уменьшается. Действующее отсечение могло преждевременно отвергать направление.
- 1201: допуск существующей доли1/4096 для пространственного ASD устранил нулевую итерацию точной цели, но30 итераций недостаточно. Холодный Mx остался NumFail,75 состояний,217,172 с, прежний максимум108,623718. My/N сохранены. В выдачу не принято.
