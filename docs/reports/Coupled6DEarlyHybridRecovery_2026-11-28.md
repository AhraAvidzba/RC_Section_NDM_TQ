# Раннее переключение на гибридный корректор ASD

## Результат и границы этапа

В частной книге найдено равновесие одной замороженной трудной пробы Mx при исходных допусках и прежнем общем бюджете 30 итераций. Автоматический прогноз после двух малых поправок передал оставшиеся 28 итераций гибридному корректору. Независимая сборка с нативными материалами OpenSees подтвердила все 60 уравнений, шесть усилий и допустимость материалов. Это локальный численный успех; физический предел этой пробой не подтверждается.

Полный холодный поиск пока не улучшен: Mx+ и чистое T остаются NumFail. Подтверждённый предел Mx− около 109,8 кН·м сохранён в двух суженных вариантах. Ни один вариант этого этапа не перенесён в рабочие исходники и пользовательскую книгу. Полная задача шести усилий остаётся активной.

## Неизменные исходные данные

Прямоугольник 300×500 мм; четыре угловых стержня Ø20 A400 при x=±102 мм, y=±202 мм; замкнутый хомут Ø8 A240 с шагом 150 мм. ASD: E=30000 МПа, ν=0,2, fc=30 МПа, ft=3 МПа, Gt=0,12 Н/мм, Gc=80 Н/мм, Lch=125 мм. Явный предел эквивалентного сжатия 0,0035; автоматический отказ по первой растягивающей трещине отключён по согласованному контракту ASD. Три станции, 25 бетонных точек, 4 продольных и 16 поперечных стальных точек, 60 неизвестных. Допуски 5·10⁻⁷ МПа и 5·10⁻⁷ относительный, локальный бюджет 30.

Hpost=1500 МПа сохранён исключительно для сопоставления с замороженными причинными тестами. Это не согласованная рабочая диаграмма: для пользовательского расчёта требуется фактическая настройка Config либо ограничение искусственной прибавки напряжений до 1% отдельно для материала и знака. Перенос этих тестовых результатов на такую рабочую диаграмму ещё не выполнен.

Расчёт секционный, с пространственным законом материала и тремя станциями; полноценная объёмная КЭ-модель на этом этапе не запускалась. Независимая проверка использует собственную сборку секционного равновесия и нативные материалы OpenSees, а не его объёмный элемент.

## Проверенные варианты

1208 — прогноз по двум последовательным малым поправкам Ньютона. Отношение невязок даёт прогноз оставшегося числа итераций; если он превышает остаток бюджета, запускается существующий гибридный корректор. Локальная проба завершилась за 7,81 с: 2 поправки Ньютона и 28 гибридных. Невязка 1,82124·10⁻⁶ МПа меньше исходного допуска 1,83854·10⁻⁶ МПа; использование предела стали 0,53315, сжатия бетона 0,08896. Первые три контрольные пробы совпали с соответствующим исходным вариантом побитно, кроме времени.

1209 — широкое включение того же приёма в холодном поиске. Получена регрессия: прежний физический предел Mx− потерян. Вариант отклонён; доказательства сохранены.

1210 — переключение разрешено только в уже существующем явном резервном вызове после численной неудачи. Все восемь возвращённых холодных историй побитно совпали с 1202. Локальная проба при включённом резерве совпала с 1208; холодного продвижения по Mx+ нет.

1211 — мелкие поправки для прогноза разрешаются только после отказа исходного линейного поиска. Локальная проба снова совпала с 1208. Предел Mx− сохранён; растяжение N получило немного другое, независимо проверенное плечо физического предела. Mx+ и T всё ещё NumFail. Число состояний и длительность не доказывают ускорение: чистое последовательное сравнение производительности не проводилось.

## Независимый контроль и сохранение данных

Проверены все 1452 возвращённых состояния 19 холодных расчётов и три набора по четыре замороженные пробы. Независимо пересчитаны усилия, калибровочные ограничения и материальные критерии. Для найденных физических пределов проверены верхние плечи с превышением материального ограничения; для осевого сжатия — допустимые состояния по обе стороны пика. Успех независимого пересчёта равновесия не подменяет статус поиска предела.

При первом повторе независимой проверки 1211 ошибочно использован адаптер старой геометрии с 43 точками; он остановился на проверке размерности. Повтор адаптером фактических 45 точек прошёл. Файл первичной ошибки сохранён рядом с последующим успешным доказательством. Физические параметры и допуски ради PASS не менялись.

Книги компилировались и сохранялись нативным Excel на D. Сверены фактические компоненты VBA, точечные изменения и неизменные компоненты. Закрытие собственных процессов подтверждено PID и временем запуска; пользовательские Excel не закрывались. Аудит переноса в рабочие 260 компонентов сохранён отдельно: частные книги содержат 269 компонентов, включая дополнительные тестовые модули; копировать их целиком нельзя.

Доказательства и воспроизводящие скрипты: `docs/reports/evidence/Coupled6DEarlyHybridRecovery_2026-11-28/Study`. Манифест сохраняет SHA-256 исходных байтов и точные ссылки на предыдущие архивы. Книги и архивы перечитаны с CRC/SHA-256. Общее оформление, интерфейс, полный приёмочный набор и целевое время 10 с не проверялись этим этапом.

Требуется совпадение всей возвращённой истории из 137 состояний; другая замороженная проба отрицательного Mx не заменяет эту проверку.
