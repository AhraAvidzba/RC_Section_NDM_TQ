# Явные ограничения ASD на Config: сохранённый кандидат и проверки ввода

Продолжение `7b23066`. В отдельной книге подготовлены выбор CDP/ASD и два поля `Coupled.ASDCompressionLimit`, `Coupled.ASDTensionLimit`. Рабочие исходники и публичная выдача этим этапом не заменены. Это промежуточная контрольная точка до обновления справки, раскладки и заключительных проверок файла.

## Данные и поведение

В фактически сохранённой исходной книге таблица `rngCoupledMaterialSettings` занимала Config!H122:M129: строки выбора пространственного закона ещё не было. В кандидате она расширена до H122:M132. Выбор CDP/ASD расположен в I130, сжатое ограничение — I131, необязательное растянутое — I132. Эти адреса относятся только к текущему расположению; рабочий reader находит ключи через именованный диапазон. Блок дополнительных классов стали перенесён на две строки вниз, `rngCoupledSteelClasses` — H134:N142. Все его исходные значения и прежние значения калибровки сохранены.

Сжатое ограничение ASD — обязательное положительное явно заданное значение. Оно оставлено пустым: нормативный источник для эквивалентной полной меры ASD этим этапом не придуман. Пустое растянутое ограничение или ноль отключает отдельный жёсткий порог; посттрещинная диаграмма продолжает работать. Положительный предел включает проверку. CDP оба поля не читает, включая ошибки Excel в неприменимых ячейках. Значение закона по умолчанию — CDP; отсутствие прежнего пользовательского выбора не подменяется выбором ASD.

`ReadWorkbookASDStrainLimits` в слое Excel переиспользует `CSystemSettingsReader` и создаёт неизменяемый объект ядра; `ConfigureWorkbookCoupledAnalysis` передаёт его в `CCoupledSectionAnalysis.Initialize`. Ядро и численный метод не изменялись. Ошибки сохраняют исходные номер, ключ и фактический адрес; дополнены именем `rngCoupledMaterialSettings`. Отмена пользователя не преобразуется в ошибку ввода.

Рабочий слой исправлен, ожидания не ослаблялись. В 1148 тот же набор дал 35 PASS / 0 FAIL. Проверены пустые, нулевые, отрицательные, корректные и чрезмерные пределы, текст, TODO, ошибки Excel, отсутствие структурной строки и неприменимость полей CDP.

Нативное сохранение частной книги удаляло некоторые дополнительные части оформления листа «Расчет». Общая таблица строк и все исходные индексы стилей сохранены; новые значения Config записаны inline. Изменены только четыре части: XML Config, стили, две ссылки именованных диапазонов в workbook.xml и VBA. Все 118 остальных частей, исходные изображения, диаграммы и объекты сохранены побайтно. Проверены значения и стили 34 335 незатронутых ячеек Config; условного форматирования в Config нет. В 1149 именно сохранный пакет повторно открыт и дал 35 PASS / 0 FAIL. Все 260 компонентов прочитаны из фактического VBA; 258 незатронутых компонентов совпали с базой, изменённый рабочий модуль и новый тестовый модуль совпали с исходниками кандидата.

Кандидат SHA-256: `ED62A0EBBF43F0564F678862A2E0483E27D512BEA3838FB25BA7A1B5EA5F5021`.

Это ручное подтверждение пользователя, а не утверждение об успешной автоматизации интерфейса. Захват изображения окон вернул ошибку GPU `0x887A0005`, доступен текст UI Automation. Проверки обоих допустимых пунктов повторно автоматизировать только ради снимка не требуется: подтверждение пользователя сохранено.
