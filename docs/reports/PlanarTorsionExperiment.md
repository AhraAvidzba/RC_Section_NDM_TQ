# Экспериментальный расчёт кручения и нормальных усилий

Ветка `codex/torsion-planar-experiment` начинается с `3e7da82`. Исходная книга содержит плоский НДМ для \(N,M_x,M_y\). Нагрузка \(T\) вводится в последний столбец `rngLoadCombinations`. Для ненулевого \(T\) заполняется блок хомута на листе «Сечения» с диаметром, шагом, защитным слоем до поверхности и расчётным сопротивлением стали хомута. Используются единицы INPUT. Положительный \(T\) направлен по часовой стрелке при взгляде вдоль \(+Z\). При \(T=0\) блок хомута не читается и начальные деформации не формируются.

Ось хомута строится внутрь достоверного наружного контура. Смещение равно сумме защитного слоя и половины диаметра. Отрезки и круговые дуги сохраняются в геометрии. Один хомут должен целиком помещаться в бетонном сечении с учётом отверстий. Ядро принимает также точную явно заданную ось. Текущий вход книги строит её по защитному слою. При непригодной оси пользователь получает причину с адресом входного блока.

Послетрещинная одноконтурная ферма принимает площадь \(A_o\) внутри оси за площадь, охваченную потоком. Для угла раскоса \(\theta=45^\circ\) поток по контуру равен \(q=|T|/(2A_o)\). С растягивающим усилием \(F_{sw}=qs\tan\theta\) сопоставляется сопротивление одного сечения хомута \(A_{sw}R_{sw}\). Здесь \(s\) — шаг хомутов по длине, \(A_{sw}=\pi d^2/4\), \(d\) — диаметр. Распределение продольной тяги \(q\cot\theta\) по длине контура использует ближайшие станции продольных стержней. Площадь внутри оси и фиксированный угол — допущения эксперимента. [Основание уравнений](../../literature/TorsionPlanar/README.md)

Начальное сжатие распределяется только по пригодным бетонным ячейкам. Его сила и два момента компенсируют начальное растяжение стали. Для этого подбираются неотрицательные весовые коэффициенты относительно равнодействующей продольной арматуры. По первой физической ветви диаграммы из этих напряжений восстанавливаются деформации \(\varepsilon_T\). При поиске \(N,M_x,M_y\) продольная деформация каждого элемента равна сумме \(\varepsilon_T\) и приращения плоскости. Напряжение и касательный модуль берутся из диаграммы по этой сумме. Внутренние усилия и деформационные пределы проверяются при полном состоянии. Бетон, замещаемый площадью стержня, не получает начального сжатия.

Results содержит отдельные строки по хомуту и продольным стержням. Для стержней видны начальное напряжение и деформация от \(T\), а также итоговое напряжение после решения \(N,M_x,M_y\). Запас хомута относится только к его сопротивлению. Подробная таблица элементов НДС показывает итоговое продольное поле.

Модель предназначена для заданного \(T\) и одного пригодного контура. Образование наклонных трещин, смятие бетонных раскосов, стеснённое коробление, совместная работа с \(Q_x,Q_y\) и проверка предельного \(T\) всего сечения требуют отдельных моделей. Исходный поиск предела \(N,M_x,M_y\), устойчивость и расчёт нормальных трещин относятся к собственным постановкам исходной книги. Нормативные проверки СП 63.13330.2018, пп. 8.1.36–8.1.42, не распространяются на произвольный контур через подстановку приведённых размеров.
