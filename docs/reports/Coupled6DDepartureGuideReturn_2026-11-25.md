# Обратный материальный корень и возврат к первоначальной цели

Дата: 25.11.2026. Ветка `codex/coupled-6d`.
Проверен отдельный вычислительный приём на настоящем сложном сочетании.
Автоматический холодный предел этим не подтверждён. Рабочая книга,
численное ядро выпуска и main не менялись.

## Почему малая невязка не разрешала принять кандидат

В диагностике неудачного резерва после H в 745 была малая лучшая невязка
материальной пробы. По одной строке журнала нельзя было понять, получен
ли пригодный следующий НДС и не мешает ли только порог прироста lambda.

749 повторяет одну штатную процедуру резерва от точной истории из
46 состояний, независимо проверенной в 747. В Newton добавлен только
читающий снимок перед неизменённой проверкой прироста lambda.
Тестовая обёртка контроллера задаёт состояние отдельного повтора;
она не выдаётся за побитный повтор всего исходного вызова из холодного
поиска. Материал, допуски, численные методы и условия приёмки не менялись.
Проверены все 255 компонентов фактически сохранённой книги.

Первоначальная проверка состава остановилась из-за порядка перечисления
тех же трёх импортированных модулей. Журнал уточнён по фактическому
обходу исходников; ни имена, ни количество модулей, ни содержание
компонентов не исключались из проверки. Полная проверка 255 компонентов
после уточнения успешна. Причина и исправление метаданных сохранены.

Наблюдаемый материальный кандидат:

| Показатель | Значение |
| --- | ---: |
| Принятый lambda | 1,0522075610360588 |
| Lambda кандидата | 1,040461057467035 |
| Изменение lambda | −0,011746503569023847 |
| Оценка погрешности lambda | 0,000022785727858599116 |
| Независимая полная невязка, МПа | 4,36873e-13 |
| Допуск, МПа | 1,17437e-6 |
| Ход по исходной пространственной секущей | −1,5472035882454876e-6 |
| Приращение новой материальной проекции | +1,4622113976685014e-6 |

Кандидат является равновесным НДС. Независимым интегрированием проверены
исходные 46 состояний и один диагностический кандидат: шесть усилий,
пространственные уравнения, связи и сталь. Но его поле движется назад
относительно принятой секущей. Положительный ход новой скалярной
проекции не заменяет проверки полного поля. Исходная управляющая
координата кандидата 0,00011522294008912698 меньше принятой
0,00011677014367737246, тогда как запрошена цель 0,0001168469282731093.

Снятие одного отсева по lambda не обосновано: независимая проверка
направления также отклоняет этот кандидат. Контроллер его не принял,
ревизия принятой истории в процедуре осталась 48. Текстовая выгрузка
дополнительной последовательности явно помечена диагностической,
не принятой ветвью и не предельным состоянием.

## Вспомогательный корень как вычислительный прогноз

В 750 обратный корень используется только как начальное приближение
для решения первоначальной линейной управляющей цели. Перед возвратом
восстановлена исходная история из 46 состояний. Обратный корень не
включён в эту историю и не расширяет допустимую область материалов.
Использован существующий API управляемого НДС, численное ядро равно 749.
Новый расчёт не является автоматическим принятием ветви контроллером.

Первая процедура повторена, её фактические затраты прочитаны из решателя:
14 основных итераций. Возврату предоставлено только 30 − 14 = 16 итераций.
Он сошёлся за 3; суммарно 17 из общего бюджета 30. Все счётчики обеих фаз
сохранены, включая вычисления невязки и гибридные матрицы.

| Показатель возврата | Значение |
| --- | ---: |
| Исходная цель | 0,0001168469282731093 |
| Фактическая управляющая координата | соответствует цели |
| Lambda возвращённого НДС | 1,0578549815983267 |
| Положительный ход в исходной проекции | 7,678459573682522e-8 |
| Невязка исходной управляющей строки, МПа | 8,13152e-16 |
| Независимая полная невязка, МПа | 6,65631e-9 |
| Допуск, МПа | 1,18565e-6 |
| Время только фазы возврата | 0,54296875 с |

0,543 с не является временем штатного расчёта от запуска до Results:
в него не входят первая процедура, подготовка, отчёт и схема. Целевое
время всей задачи этим не подтверждается. Значение lambda относится
к конкретной проблемной точке раннего H, не является новым рекордом
холодного поиска и не сравнивается как предел с историей 743.

Повторенный вспомогательный кандидат побитно совпал с кандидатом 749.
Возвращённый НДС и исходная управляющая цель проверены независимо:
все шесть усилий, пространственные уравнения и связи. Диагностическая
последовательность возврата содержит ровно исходные 46 состояний и
возвращённую точку, без промежуточного обратного корня. Во время решения
ревизия принятой истории не менялась. Нативный счётчик 1/0 относится
к направленной проверке, не к поиску предела всего сечения.

Книга 750 скомпилирована, сохранена и проверена по всем 255 компонентам.
Доступ к VBComponents при подготовке задержался, затем завершился сам.
Компилятор и собственный Excel завершились штатно; принудительного
закрытия не потребовалось. Пользовательские Excel не затрагивались.

## Следующий этап интеграции

Приём следует проверить внутри автоматической процедуры резерва:
равновесный материальный кандидат служит только прогнозом возврата
к сохранённым исходным проекции и цели. Вспомогательный материал не
принимается; история, сталь, равновесие, направление и точность предела
проверяются прежними условиями. Все затраты возврата должны войти
в оставшийся общий бюджет и счётчики исходного вызова; рекурсивное
повторение резерва необходимо исключить.

Базой следующего частного варианта остаётся 743 с поздним H, а не
неудачный ранний H из 745. После интеграции обязательны направленные
регрессии, повтор контрольной точки и настоящий холодный Both/Excel
с сохранением и повторным открытием книги. Для объявления предела
по-прежнему необходим физический механизм; подтверждённый НДС и
положительный ход поля сами по себе этого не доказывают.

ONQ-012, автоматический предел сложного сочетания, полнота LoadPath,
внешний контроль одинаковых моделей, скорость и полная приёмка
Excel/AutoCAD остаются открытыми. Полный объём цели сохранён.
