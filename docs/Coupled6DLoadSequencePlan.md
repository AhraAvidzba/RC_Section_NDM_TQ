# Последовательность проверки составляющих нагрузки

Указание пользователя от 27.11.2026: **N → M → T → NMT → Q → NMTQ**. Сначала разбираются отдельные составляющие; к совместной задаче возвращаемся после их проверки. Новые исследования с Q до этапа Q не запускаются. Ранее полученные данные сохраняются и не означают завершения соответствующего этапа.

| Этап | Содержание | Текущее состояние |
| --- | --- | --- |
| N | Чистое растяжение и сжатие; явный путь λ*N | Арматурное событие растяжения локализовано при N₀=10/100 кН; максимум сжатия ASD подтверждён с холодным повтором, полной ветвью и Fail при перегрузке; оба предела плоского N проверены; CDP, прямое НДС и перенос в рабочее ядро остаются открытыми |
| M | Чистый изгиб, необходимые направления; повторяемость при разных исходных моментах | Есть арматурный предел одного примера; выявлена зависимость продвижения от исходного момента |
| T | Чистое кручение; продольная и поперечная сталь; отказ хомута | Есть воспроизводимое арматурное событие около 3,662 кН·м и Fail при T=4 кН·м; общий бетонный предел не завершён |
| NMT | N+Mx+My+T при Qx=Qy=0; выбранный LoadPath | Отложено после отдельных N/M/T; контроль 1037 дал λ=1,61005 без подтверждённого физического предела |
| Q | Отдельно Qx и Qy, необходимые направления | Новые исследования отложены |
| NMTQ | Все шесть усилий и требуемые траектории | Новые исследования отложены до предыдущих этапов |

На каждом этапе отдельно фиксируются: пригодность НДС при заданной нагрузке; достигнутый физический критерий; равновесие всех уравнений и результирующих; независимый контроль материалов и расчётных состояний; повтор с нулевой материальной историей; влияние размера шага и масштаба исходной нагрузки; время вызова и отдельно полного пользовательского запуска.

Текущий осевой этап: [исходные контроли и отрицательные повторы](reports/Coupled6DPureAxial_2026-11-27.md), [исправленная локализация растянутой стали при двух масштабах N](reports/Coupled6DAxialEventPredictor_2026-11-27.md), [подтверждённый максимум сжатия ASD и отказ перегруженного сечения](reports/Coupled6DAxialCompressionLimit_2026-11-27.md), [осевые пределы действующей плоской НДМ без продолжения диаграмм](reports/Coupled6DPlanarAxialReference_2026-11-27.md). Наличие одного найденного критерия не закрывает весь этап N.

Успешное исполнение тестового макроса, последнее равновесие, локальный максимум или NumFail сами по себе не подтверждают полную несущую способность. Достижение деформационного предела конкретной арматуры ниже исходной нагрузки достаточно для Fail по этой арматуре. Для общего Pass должны быть выполнены все применимые физические проверки, включая бетон.

Приоритет разработки — ASD; CDP сохраняется для сравнения. Сопоставление с плоской НДМ явно учитывает различие фактических материалов и постановок. Совпадение только одноосных таблиц не означает совпадения всего пространственного закона.

Настройка [перекрёстного повреждения ASD](Coupled6DASDCrossDamagePlan.md) остаётся отложенной до стабилизации ядра. [Серия Wang–Huang 2017](Coupled6DExperimentalComparisonPlan.md), геометрия, пользовательские статусы, LoadPath, вывод Results, интерфейс и итоговая приёмка остаются в полном объёме исходной задачи.
